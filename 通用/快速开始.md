# 魔兽世界性能优化 - 快速开始指南

## 🚀 立即执行的5个步骤

### 步骤1: 更新显卡驱动 (5分钟)
```
1. 访问 NVIDIA官网下载最新驱动
2. 或使用GeForce Experience自动更新
3. 重启电脑
预期提升: 5-10% FPS
```

### 步骤2: 调整游戏内关键设置 (10分钟)
```lua
-- 在游戏聊天框输入:
/console gxapi "D3D11"
/console maxfps 144
/console ShadowTextureSize 512
/console GroundClutterDensity 50

-- 在图形设置中:
视野距离: 5-6
地面阴影: 关闭
液体细节: 低
投射物轨迹: 低
```
预期提升: 15-25% FPS

### 步骤3: 禁用不必要的插件 (10分钟)
```
打开游戏 → 角色选择界面 → AddOns按钮

建议禁用的插件:
□ Atlas系列 (如不常用)
□ GatherMate2_Data
□ BuyEmAllClassic
□ MountJournalEnhanced
□ WhatsTraining

保留核心插件:
✓ WeakAuras
✓ DBM-Core
✓ Details!
✓ Decursive
```
预期提升: 10-20% FPS

### 步骤4: 优化WeakAuras (15分钟)
```
1. 输入 /wa 打开WA面板
2. 点击"统计"标签查看最耗时的WA
3. 对高频WA调整刷新率:
   - 从0.1秒改为0.2-0.3秒
4. 禁用未激活状态的显示
5. 删除超过1个月未使用的WA
```
预期提升: 10-30% FPS (取决于WA数量)

### 步骤5: Windows系统优化 (5分钟)
```
1. 电源选项 → 高性能模式
2. 关闭后台程序(浏览器、视频播放器等)
3. 游戏模式下运行
4. NVIDIA控制面板 → 最高性能优先
```
预期提升: 5-10% FPS

## ⚠️ 常见问题速查

### Q1: 优化后还是卡?
```
检查项:
□ CPU/GPU温度是否过高(>85°C)
□ 是否使用SSD安装游戏
□ 是否有后台程序占用资源
□ WA脚本是否过多(>100个)
□ 插件是否需要更新
```

### Q2: 画面变差太多?
```
逐步恢复设置:
1. 先提高纹理分辨率(对性能影响小)
2. 再提高环境细节
3. 最后调整视野距离
找到画质和性能的平衡点
```

### Q3: 某些WA不能用了?
```
解决方法:
1. 检查WA是否过期
2. 确认天赋配置匹配
3. 查看BugSack中的错误
4. 重新导入最新版WA
```

### Q4: 登录游戏很慢?
```
原因: SavedVariables文件过大
解决:
1. 备份WTF文件夹
2. 删除旧的SavedVariables
3. 重新配置必要的设置
```
