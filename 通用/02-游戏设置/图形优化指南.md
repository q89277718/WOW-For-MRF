# 魔兽世界图形设置优化指南

## 目标
在保持良好视觉效果的前提下,最大化帧数(FPS)

---

## 🎯 推荐设置(基于RTX 3070 + i9-10900K)

### 显示设置
```
分辨率: 1920x1080 (或您的显示器原生分辨率)
刷新率: 匹配显示器最高刷新率(建议144Hz+)
窗口模式: 全屏独占(性能最佳)
垂直同步: 关闭
三重缓冲: 关闭
```

### 图形质量预设
**基础预设**: 7-8级(高)

### 高级图形设置详解

#### 🔴 对性能影响最大的设置(优先调整)

| 设置项 | 推荐值 | 说明 |
|--------|--------|------|
| **视野距离** | 5-6级 | 每提升1级显著降低FPS |
| **地面阴影** | 关闭/低 | 主城和团队副本中影响巨大 |
| **液体细节** | 低 | 水面效果,对战斗无影响 |
| **投射物轨迹** | 低 | 法术特效,可降低GPU负担 |
| **粒子密度** | 中 | 技能特效数量 |

#### 🟡 中等影响设置

| 设置项 | 推荐值 | 说明 |
|--------|--------|------|
| **纹理分辨率** | 高 | RTX 3070显存充足,可开高 |
| **环境细节** | 中-高 | 远景物体细节 |
| **光影效果** | 中 | 动态光照 |
| **后期处理** | 中 | 景深、光晕等效果 |
| **抗锯齿** | SMAA/FXAA | 避免MSAA(性能消耗大) |

#### 🟢 轻微影响设置

| 设置项 | 推荐值 | 说明 |
|--------|--------|------|
| **角色细节** | 高 | 玩家模型精度 |
| **天气效果** | 中 | 雨雪等天气 |
| **毛发细节** | 低-中 | 仅影响部分种族 |
| **体积雾** | 关闭 | 氛围效果,可选 |
| **景深** | 关闭 | 不影响 gameplay |

## ⚙️ 控制台命令优化

在游戏聊天框输入以下命令(需要解锁高级设置):

### 基础优化命令
```lua
/console gxapi "D3D11"                    -- 使用DirectX 11 API
/console maxfps 144                       -- 限制最大帧数(根据显示器)
/console maxfpsbk 30                      -- 后台帧数限制
/console Sound_OutputDriverName "System Default"  -- 音频驱动
```

### 进阶优化命令
```lua
/console SpellEffectLevel 6               -- 法术特效等级(1-10)
/console GroundClutterDensity 50          -- 地面杂物密度(0-100)
/console WaterDetail 1                    -- 水体细节(0-3)
/console ShadowTextureSize 512            -- 阴影贴图大小(256/512/1024/2048)
/console SunShadowTextureSize 512         -- 阳光阴影大小
```

### WA相关优化
```lua
/console NameplateMaxDistance 40          -- 姓名板显示距离
/console NameplateLargeBottomInset 0.5    -- 姓名板位置调整
/console ShowVKeyBindText 0               -- 隐藏按键提示
```

## 🔧 NVIDIA控制面板优化

### 3D设置管理
1. 打开NVIDIA控制面板
2. 管理3D设置 → 程序设置
3. 添加魔兽世界主程序(WoW.exe)
4. 调整以下设置:

```
电源管理模式: 最高性能优先
纹理过滤 - 质量: 高性能
垂直同步: 关闭
最大预渲染帧数: 1
线程优化: 开启
```

## ⚠️ 常见问题排查

### 问题1: 帧数突然下降
**可能原因**:
- 温度过高导致降频
- 后台程序占用资源
- 插件内存泄漏

**解决方法**:
1. 检查CPU/GPU温度(正常<85°C)
2. 关闭浏览器、视频播放器等
3. 禁用最近安装的插件

### 问题2: 卡顿/掉帧
**可能原因**:
- 硬盘读取慢
- 插件过多
- WA脚本复杂度过高

**解决方法**:
1. 确保游戏安装在SSD
2. 清理不用的AddOns
3. 优化WA脚本(见04-WA优化文件夹)

### 问题3: 输入延迟
**可能原因**:
- 垂直同步开启
- 三重缓冲开启
- 鼠标轮询率过低

**解决方法**:
1. 关闭垂直同步和三重缓冲
2. 使用游戏鼠标(1000Hz轮询率)
3. 降低输入延迟相关的图形设置

## 🎯 测试流程

1. **基准测试**: 在主城记录当前FPS
2. **逐项调整**: 每次只改一个设置,观察变化
3. **实战测试**: 进入副本/战场验证实际表现
4. **记录对比**: 保存优化前后的数据

建议使用 `/console fps 1` 持续监控帧数变化。
