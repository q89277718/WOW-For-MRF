# 魔兽世界插件性能优化清单

## 📋 当前插件分析

基于您的AddOns文件夹,检测到以下主要插件:

### 🔴 高资源占用插件(需重点关注)
- **WeakAuras** - WA脚本管理器(大量自定义WA会显著降低FPS)
- **Details!** - 伤害统计(实时数据处理消耗CPU)
- **Plater** - 姓名板美化(每个玩家/NPC都渲染)
- **DBM系列** - Boss计时器(多个模块同时运行)
- **Rurutia** - 自定义框架(可能包含复杂逻辑)

### 🟡 中等占用插件
- **!Pig** - UI整合包(包含多个子模块)
- **AtlasLootMY** - 掉落查询(数据量大)
- **NDui** - UI美化
- **Decursive** - 驱散助手
- **ThreatClassic2** - 仇恨监控

### 🟢 低占用插件
- **BugSack/!BugGrabber** - 错误捕获
- **Accountant_Classic** - 金币追踪
- **AlreadyKnown** - 配方标记
- **MailLogger** - 邮件记录

### 策略2: 优化高占用插件设置

#### WeakAuras优化
```lua
-- 在WA选项中调整:
1. 关闭"显示未激活的aura"
2. 减少刷新率(从0.1秒改为0.2秒)
3. 禁用不必要的动画效果
4. 合并功能相似的WA组
5. 删除长期不用的WA

-- 检查WA数量:
/chat命令输入 /wa
查看总触发器数量,建议控制在50个以内
```

#### Details!优化
```lua
-- 在Details选项中:
1. 关闭窗口动画
2. 减少数据保留时间(从永久改为单次会话)
3. 禁用详细日志记录
4. 关闭自动截图
5. 限制显示的窗口数量(只保留主窗口)
```

#### Plater姓名板优化
```lua
-- 在Plater选项中:
1. 降低更新频率(从0.05改为0.1)
2. 简化姓名板样式(减少特效)
3. 关闭血条动画
4. 减少显示的信息量
5. 禁用鼠标悬停时的额外效果
```

#### DBM优化
```lua
-- 在DBM选项中:
1. 只加载需要的副本模块
2. 关闭声音提示(如果不需要)
3. 减少计时器显示数量
4. 禁用战斗记录保存
5. 关闭自动报告功能
```

## 🔧 高级优化技巧

### 1. 延迟加载插件
创建 `load.xml` 文件控制加载顺序:
```xml
<Ui>
    <Script file="Core.lua"/>
    <!-- 只在需要时加载 -->
    <Include file="OptionalModule.xml" loadOnDemand="true"/>
</Ui>
```

### 2. 清理插件缓存
```
定期删除以下文件夹(游戏会重新生成):
- WTF/Account/[账号]/SavedVariables/
- Interface/AddOns/[插件名]/Cache/
```

### 3. 使用AddonControlPanel
安装 ACP 插件(您已安装):
```
1. 游戏中输入 /acp
2. 勾选/取消勾选插件
3. 无需重启即可生效
4. 快速切换不同配置
```

### 4. 内存监控
```lua
-- 聊天框输入:
/script CollectGarbage()
/memory
-- 查看各插件内存占用
```

## ⚠️ 常见性能陷阱

### 陷阱1: WA脚本过多
**症状**: FPS随时间逐渐下降  
**原因**: WA触发器累积,未及时清理  
**解决**: 
- 定期审查WA列表
- 删除过期/重复的WA
- 使用WA分组管理

### 陷阱2: 插件冲突
**症状**: 随机卡顿、报错  
**原因**: 多个插件修改同一UI元素  
**解决**:
- 检查BugSack中的错误
- 逐一禁用排查冲突源
- 更新所有插件到最新版

### 陷阱3:  SavedVariables过大
**症状**: 登录游戏缓慢  
**原因**: 插件保存的数据文件过大  
**解决**:
- 清理旧的战斗记录
- 重置不常用插件的设置
- 定期备份并清空SavedVariables
