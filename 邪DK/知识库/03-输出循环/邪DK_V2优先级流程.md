# 邪DK V2 优先级流程

**作者**：墨染风  
**架构**：纯优先级APL（参照鸟德V2），无状态机，每帧独立评估

---

## 全局规则

- 保持双病（冰霜疫病 + 血之疫病）全程覆盖
- 孤寂 buff ≤3s → 补鲜血打击（5%增伤，持续20s）
- 食尸鬼狂乱 ≤5s → 补（活力分流 + 食尸鬼狂乱）
- AOE：每帧检测 nameplate ≥2目标 → 传染替代鲜血打击 + 枯萎凋零优先
- 符文追踪：冰/邪/血各2枚（CLEU驱动 + 读条预测）

## 爆发节奏

- 石像鬼CD（3min）≤15s → 进入爆发准备
- 石像鬼CD ≤5s → 正式爆发 + 重置黑魔法标志
- 大军CD（8min）≤5s 且石像鬼已用（CD>150s）→ 大军就绪也触发爆发

## AOE 逻辑

- 每帧检测 nameplate 8码内目标数
- ≥2目标时：鲜血打击→传染 / 枯萎凋零优先级提升 / 天灾打击→血液沸腾
- 传染阈值可通过配置调整（默认2目标）
