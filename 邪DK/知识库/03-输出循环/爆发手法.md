# 爆发手法详解 

##  开怪爆发循环 (OP_BOSS - 16步)

### 完整流程

```
起1: 冰冷触摸     → 上冰霜疫病（远程≤30码）
起2: 暗影打击     → 上血之疫病（近战≤5码）
起3: 鲜血打击     → 5%增伤buff（孤寂天赋触发）
起4: 天灾打击     → 核心伤害技能
起5: 鲜血打击     → 维持5%增伤buff
起6: 寒冬号角     → 提升攻强（如CD且RP≥60则跳过）
天鬼: 召唤石像鬼  →  快照攻强，实时急速
      ↓ 自动切绿脸（让天鬼享受15%急速）
⭐: 加速手套+炸弹 → oStep 7-9时使用，让大军享受15秒急速
符武: 符文武器增效 → 重置所有符文和符文能量
凋零: 枯萎凋零    → AOE伤害
大军: 亡者大军    →  享受手套急速buff（55%急速）
过1-11: 过渡技能  → 补疾病、打伤害
切红脸: 鲜血灵气  → 切换到血脸进行常规循环
```

## 🔥 战斗前预铺手法（关键！）

### 倒数8-10秒准备

```
倒数10秒：邪恶灵气（切绿脸）
倒数9秒：  白骨之盾
倒数8秒：  食尸鬼狂乱（持续30秒）← 关键！避免开怪浪费GCD
```

**为什么预铺狂乱？**
- 食尸鬼狂乱持续30秒
- 如果在开怪时释放，会占用宝贵的GCD
- 预铺后，开怪时正好覆盖整个爆发期
- 节省2个GCD用于输出技能

## ⚡ 关键时机说明

### 1. 手套+炸弹使用时机

**最佳时机**：oStep 7-9之间（召唤石像鬼后、亡者大军前）

**原因**：
- 手套提供15%急速，持续15秒
- 亡者大军的12个骷髅享受完整15秒急速增益
- 宠物急速达到55%（狂乱25% + 绿脸15% + 手套15%）
- 大幅提升大军DPS

**代码实现**：
```lua
if not _bombsUsed and oStep >= 7 and oStep <= 9 and IsGlovesReady() then
    return { spell = "加速手套", ... }
end
```

### 2. 天鬼后切绿脸

**机制**：
- 召唤石像鬼后设置`_needSwitchToUnholyAfterGA`标志
- GetOpener/GetNormal中最高优先级检查
- 如果不是绿脸，立即切换

**原因**：
- 泰坦时光服特殊机制：天鬼接受实时急速
- 绿脸提供15%宠物急速
- 让天鬼在30秒持续时间内享受急速增益

### 3. 寒冬号角CD处理

**问题**：如果战斗前已经用了寒冬号角，爆发时号角在CD，会卡住循环

**解决方案**：
```lua
if oStep == 6 and IsCD(S.HN) and GetRP() >= 60 then
    oStep = 7  // 跳过寒冬号角
end
```

## 📊 爆发期伤害构成

### 宠物急速体系

```
食尸鬼狂乱(25%) + 绿脸(15%) + 手套(15%) = 55%急速
```

**实际收益**：
- 假设宠物基础DPS：1000
- 食尸鬼雕文后：1000 × 1.4 = 1400
- 55%急速期间：1400 × 1.35 ≈ 1890
- **最终宠物DPS：约1890（+89%）**

### 天鬼伤害

- 快照机制：记录施放时的AP
- 实时急速：享受当前急速增益（绿脸15%）
- 30秒持续时间内造成大量伤害

### 亡者大军伤害

- 12个骷髅，每个持续30秒
- 享受55%急速增益
- 配合速度药水效果更佳

## 🎮 实战操作指南

### 手动操作流程

1. **倒数10秒**：按`/cast 邪恶灵气`
2. **倒数9秒**：按`/cast 白骨之盾`
3. **倒数8秒**：按`/cast 食尸鬼狂乱`
4. **倒数3秒**：选中目标
5. **倒数0秒**：开始输出（WA脚本自动接管）

### WA脚本自动化

使用哀冬虚空之花框架的WA脚本，只需：
1. 导入字符串
2. 设置配置参数
3. 战斗中脚本自动判断最优技能

**无需手动操作！**

## ️ 注意事项

1. **确保双病覆盖**：冰霜疫病和血之疫病必须全程保持
2. **保持孤寂buff**：每20秒至少打一次鲜血打击
3. **保持冰冷之爪buff**：冰霜疫病≤3秒时优先补冰触
4. **手套只使用一次**：_bombsUsed标志确保一场战斗只使用一次
5. **天鬼后立即切绿脸**：让天鬼享受15%急速
