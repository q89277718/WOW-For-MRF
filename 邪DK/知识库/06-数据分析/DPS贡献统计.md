## 🔥 三大协同体系详细计算

### 1. 白字三重放大体系

```
冰冷之爪(20%攻速) × 坚若精钢(副手+25%) × 骨疽(+20%暗影)
```

**计算示例**：
```
假设基础白字DPS：1000
├─ 冰冷之爪后：1000 × 1.2 = 1200
├─ 坚若精钢副手加成：副手部分额外+25%
└─ 骨疽附加：1200 × 20% = 240暗影伤害

最终白字DPS：约1500-1600
实际提升：+50-60%
```

---

### 2. 天灾打击多重增伤体系

```
险恶攻击(暴击+6%，暴伤+30%) × 不纯(AP×20%) × 黑色热疫使者(魔法易伤13%) × 瑞文戴尔之怒(血疫病目标+10%)
```

**计算示例**：
```
假设天灾打击基础伤害：5000
├─ 不纯加成：5000 + AP×20%（假设AP=5000）= 6000
├─ 黑色热疫使者：6000 × 1.13 = 6780
├─ 瑞文戴尔之怒：6780 × 1.1 = 7458
└─ 险恶攻击期望：7458 × (1 + 11%×195% - 5%×150%) ≈ 8497

最终期望伤害：约8500
实际提升：+70%
```

---

### 3. 疾病伤害倍增体系

```
墓穴热病(+30%) × 黑色热疫使者(转化，魔法易伤13%) × 瑞文戴尔之怒(血疫病目标+10%)
```

**计算示例**：
```
假设双病基础DOT每秒：100
├─ 墓穴热病：100 × 1.3 = 130
├─ 黑色热疫使者：130 × 1.13 = 146.9
└─ 瑞文戴尔之怒：146.9 × 1.1 = 161.6

最终DOT每秒：约162
实际提升：+62%
```

### 4. 爆发期宠物急速体系

```
食尸鬼狂乱(25%急速) × 邪恶灵气(15%急速) × 加速手套(15%急速)

假设宠物基础DPS：1000

└─ 绿脸+手套叠加：1750 × 1.35 ≈ 2363

最终宠物DPS：约2363
实际提升：+136%
```

## 📈 装备属性优先级

### 泰坦时光服初期（当前阶段）

```
命中(8%) > 力量 > 急速 > 精准(26) > 暴击 > 破甲
```

**详细说明**：

1. **命中等级**（8%）：确保技能不会miss，优先堆满
2. **力量**：直接提升所有物理和法术伤害
3. **急速**：缩短GCD和符文回复时间，提高输出频率
4. **精准等级**（26）：减少被躲闪和招架的几率
5. **暴击等级**：配合险恶攻击天赋，提升暴击收益
6. **破甲等级**：降低目标护甲，提升物理伤害
