# 邪DK天打流 APL - 泰坦时光服优化版

## 📋 概述

这是为**魔兽世界泰坦时光服**（基于WLK 80级框架）优化的不死亡灵骑士（邪DK）自动输出循环脚本。采用"天打流"核心机制，通过WeakAuras插件实现智能技能优先级管理。

**原作者**：疯狂不龟路  
**深度重构**：念秋  
**泰坦时光服适配**：当前版本

---

## ✨ 核心特性

### 1. 智能姿态管理
- ✅ **天鬼后自动切绿脸**：召唤石像鬼后自动切换邪恶灵气，让天鬼享受实时急速增益
- ✅ **开怪前自动准备**：战斗外检测天鬼CD，提前10秒切绿脸准备

### 2. 爆发手法优化
- ✅ **支持预铺狂乱**：移除开怪循环中的食尸鬼狂乱和活力分流，支持战斗前预铺30秒狂乱buff
- ✅ **智能狂乱补充**：buff剩余≤5秒时自动补充（活力分流+食尸鬼狂乱），避免开怪时浪费分流
- ✅ **炸弹最佳时机**：爆发期（石像鬼后、大军前）使用手套+炸弹，让亡者大军享受15秒急速buff
- ✅ **黑魔法宏集成**：oStep 8-9时提示使用黑魔法宏（凋零缠绕+工程炸药/炸弹+切换武器）
- ✅ **爆发宏集成**：oStep 10时提示使用爆发宏（种族特长+手套+饰品+药水+速度药水+切换武器）

### 3. 动态AOE适配
- ✅ **智能目标检测**：2个及以上额外目标时自动切换到AOE循环（使用传染）
- ✅ **无缝切换**：根据战斗场景动态调整单体/AOE循环

### 4. 资源管理优化
- ✅ **符文能量泄能**：RP≥90时强制使用凋零缠绕，避免溢出
- ✅ **空窗期填充**：技能CD时智能使用凋零缠绕/寒冬号角/手套填充
- ✅ **容错机制**：技能被抵抗/未命中时自动回退步骤

```lua
触发条件：
- Boss战
- 开启了自动爆发
- 天鬼CD就绪
- 符文能量 ≥ 60

执行时机：每轮开始时（nSub == 1）优先检查
```

**狂乱buff补充**：
```lua
触发条件：
- Boss战
- 狂乱buff ≤ 5秒 或已消失
- 活力分流和食尸鬼狂乱都可用

插入位置：每轮开始时优先执行
├─ _gfInsert == 1: 活力分流 (BT)
└─ _gfInsert == 2: 食尸鬼狂乱 (GF)
```

**符文能量泄能**：
```lua
空窗期泄能：RP ≥ 60 时使用凋零缠绕（适配符文能量掌握天赋）

```

### 🎯 黑魔法宏和爆发宏使用说明

#### **黑魔法宏**（oStep 8-9时提示使用）

**使用时机**：召唤石像鬼后、亡者大军前

**宏内容**：
```lua
#showtooltip
/施放 凋零缠绕
/施放 心灵冰冻
/use [group:raid] 通用热力工程炸药
/use [@player,group:raid] 萨隆邪铁炸弹
/equipset 黑魔法
/cqs
```

**作用**：
- 凋零缠绕：消耗RP造成伤害
- 心灵冰冻：打断目标施法（可选）
- 工程炸药/炸弹：额外伤害（不占GCD）
- 切换黑魔法武器：获得武器附魔增益
- /cqs：清除队列延迟

---

#### **爆发宏**（oStep 10时提示使用）

**使用时机**：亡者大军步骤时

**宏内容**：
```lua
#showtooltip 
/cast [nochanneling]  狮心        -- 种族特长（人类）
/use [nochanneling]  13          -- 手套（工程学加速手套）
/use [nochanneling] 14          -- 饰品1
/use [nochanneling] 10          -- 饰品2
/use [group:raid,nochanneling] 速度药水
/equipset 十字军                -- 切换十字军武器
```

**作用**：
- 种族特长：提升攻击力（根据种族不同）
- 手套：15%急速，持续15秒
- 饰品：主动饰品效果
- 速度药水：提升急速
- 切换十字军武器：获得武器附魔增益

---

#### **使用流程**

1. **WA脚本提示**：当到达oStep 8-9时，WA会显示“黑魔法宏”
2. **手动触发**：点击你设置的黑魔法宏
3. **继续输出**：WA会自动进入下一步（亡者大军）
4. **再次提示**：当到达oStep 10时，WA会显示“爆发宏”
5. **手动触发**：点击你设置的爆发宏
6. **自动继续**：WA会继续后续的输出循环

**注意事项**：
- ✅ 这两个宏需要你自己创建并放在技能栏上
- ✅ WA只会提示时机，不会自动释放（因为涉及装备切换）
- ✅ 确保在提示时立即点击，避免错过最佳时机
- ✅ 一场战斗只使用一次，_blackMagicUsed和_burstMacroUsed标志会防止重复
```

## ⚠️ 重要注意事项

### 1. 战斗前准备
- **必须预铺狂乱**：倒数8秒时手动点击预铺宏
- **确保绿脸**：天鬼需要绿脸的急速增益
- **骨盾覆盖**：提前开启白骨之盾

### 2. 手套使用时机
- **爆发期使用**：在召唤石像鬼后、亡者大军前自动使用
- **只使用一次**：手套CD是1分钟，一场战斗通常只用1次
- **近战范围**：必须在≤5码才能使用（炸弹需要命中目标）

### 3. 姿态切换
- **开怪前**：绿脸（最大化天鬼和食尸鬼伤害）
- **开怪后**：血脸（获得5%增伤和威胁值降低）
- **天鬼后**：自动切绿脸（实时急速增益）

### 4. 容错机制
- **技能抵抗**：自动回退步骤，重新释放
- **技能CD**：自动使用填充技能等待
- **移动战**：灵活使用凋零缠绕填充

## 🎮 使用流程

### 1. 导入WA
1. 复制 `邪dk.wa.ini` 文件内容
2. 游戏中输入 `/wa` 打开WeakAuras
3. 点击"导入"，粘贴代码
4. 确认导入成功

### 2. 配置参数
1. 在WA中找到"疯狂念秋"aura
2. 展开"选项"面板
3. 勾选上述配置参数
4. 保存配置

### 3. 战斗中使用
1. **战斗前8秒**：点击预铺宏（绿脸+骨盾+狂乱）
2. **开怪**：WA自动接管，执行爆发循环
3. **常规阶段**：完全自动化，专注走位和机制
4. **战斗中**：如有需要可手动干预（如紧急位移）
