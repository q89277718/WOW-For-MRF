# 魔兽世界泰坦时光服 - 知识库与自动化脚本

> 专为**泰坦重铸「时光」服务器**（基于 WLK 80 级框架）打造的综合性游戏知识库和 WeakAuras 自动战斗脚本合集。

---

## 项目简介

本项目围绕魔兽世界泰坦时光服，提供多职业的智能输出循环脚本、天赋配置指南、实战技巧以及通用的游戏性能优化方案。核心目标是通过 WeakAuras 自动化脚本帮助玩家最大化 DPS 输出，同时提供完整的理论知识支撑。

**技术栈**：Lua / WeakAuras / VF 框架（虚空之花）

## 各模块概览

### 邪DK - 天打流 APL（核心模块）

| 特性 | 说明 |
|------|------|
| 智能姿态管理 | 天鬼后自动切绿脸，让宠物享受实时急速增益 |
| 爆发手法优化 | 支持战斗前预铺狂乱，移除开怪时浪费的 GCD |
| 动态 AOE 适配 | ≥2 额外目标时自动切换单体/AOE 循环 |
| 资源管理 | 符文能量泄能机制，避免溢出损失 |
| 容错机制 | 技能抵抗自动回退，大军失败补偿 |

**预期提升**：相比传统手动循环 **8-14% DPS**

### 鸟德 - 轨道炮系统

| 特性 | 说明 |
|------|------|
| 自然之力优化 | Boss 战立即召唤，确保吃满嗜血急速加成 |
| 嗜血检测 | 有嗜血优先星火，无嗜血优先愤怒 |
| 轨道炮智能延迟 | 避免最后出现疲软期，最大化 buff 覆盖 |
| 斩杀期优化 | Boss 剩余 <10 秒不开炮 |

**预期提升**：单体 Boss **8-12%**，短时间战斗 **10-15%**

### 法师 - 三专精指南

覆盖奥术、火焰、冰霜三个专精的天赋配置、输出循环和 WA 脚本，包含法纹布快速制作等辅助工具。

### 猎人 - P4 属性换算

提供兽王猎 P4 阶段的属性 AP 换算表、BIS 装推荐和装备对比计算方法。属性优先级：命中(263/8%) > 强度 > 敏捷 > 暴击 > 破甲 > 智力 > 急速。

### 通用 - 性能优化

5 步快速优化流程，预期 FPS 提升 **50-100%**：
1. 更新显卡驱动
2. 调整游戏内关键设置
3. 禁用不必要的插件
4. 优化 WeakAuras
5. Windows 系统优化

## 快速开始

### 前置要求

- 魔兽世界 WLK Classic 客户端
- WeakAuras 插件
- VF 框架（虚空之花）— 提供 `VF_getSpellCD`、`VF_getBuff` 等自定义函数

### 使用步骤

1. 进入对应职业目录，阅读该职业的 README 或文档
2. 复制 `.wa.ini` 或 `.lua` 脚本内容
3. 游戏中输入 `/wa` → 导入 → 粘贴代码
4. 根据文档配置参数
5. 按照输出循环指南进行实战练习
