## ⭐ 核心知识点速查

### **最关键的天赋（必须点满）**
1. **冰冷之爪 (5/5)** - 20%攻速，白字核心
2. **坚若精钢 (3/3)** - 副手+25%伤害，双持核心
3. **险恶攻击 (2/2)** - 天打暴击+6%，暴伤+30%
4. **骨疽 (5/5)** - 普攻附加20%暗影伤害
5. **不纯 (5/5)** - 法术伤害=AP×20%
6. **食尸鬼狂乱 (1/1)** - 宠物25%急速，30秒
7. **黑色热疫使者 (3/3)** - 魔法易伤13%+暴击3%
8. **瑞文戴尔之怒 (5/5)** - 血疫病目标伤害+10%
9. **召唤石像鬼 (1/1)** - 终极爆发宠物

### **最关键的雕文**
1. **枯萎凋零雕文** - 凋零伤害+20%（AOE核心）
2. **食尸鬼雕文** - 宠物属性+40%（爆发核心）
3. **黑暗死亡雕文** - 死缠伤害+15%（单体优化）

### **三大协同体系**
1. **白字三重放大**：冰冷之爪 × 坚若精钢 × 骨疽 = +50-60%
2. **天打多重增伤**：险恶攻击 × 不纯 × 黑色热疫使者 × 瑞文戴尔之怒 = +70%
3. **爆发期宠物急速**：食尸鬼狂乱 + 绿脸 + 手套 = 55%急速

### **WA脚本关键参数**
- RP上限：130（符文能量掌握天赋）
- 空窗期泄能阈值：60
- 循环中泄能阈值：120
- AOE触发阈值：2个及以上额外目标
- 冰霜疫病保活阈值：≤3秒优先补冰触
