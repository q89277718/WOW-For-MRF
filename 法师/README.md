## ⚡ 法师专精选择

### 1. 奥术法师 (Arcane)
- **特点**：爆发高，机动性强
- **适用场景**：单体Boss战、移动战
- **核心机制**：奥术充能层数管理

### 2. 火焰法师 (Fire)
- **特点**：持续伤害稳定，暴击收益高
- **适用场景**：长时间战斗、多目标战斗
- **核心机制**：点燃连击、活体炸弹

### 3. 冰霜法师 (Frost)
- **特点**：控制能力强，生存性好
- **适用场景**：PVP、需要控制的副本
- **核心机制**：寒冰指触发、深冬之寒
