## ⚡ 专精选择

### 奥术法师 (Arcane)
- **核心天赋**：奥术潜能、法术能量
- **关键技能**：奥术飞弹、奥术弹幕
- **适用场景**：单体爆发、移动战

### 火焰法师 (Fire)
- **核心天赋**：点燃、活体炸弹
- **关键技能**：火球术、炎爆术
- **适用场景**：持续输出、多目标战斗

### 冰霜法师 (Frost)
- **核心天赋**：寒冰指、深冬之寒
- **关键技能**：寒冰箭、冰枪术
- **适用场景**：控制型战斗、PVP
