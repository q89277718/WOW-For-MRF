# 法纹布快速制作WA脚本

## 📋 概述

这是一个用于快速制作法纹布的WeakAuras脚本，通过点击WA图标自动打开裁缝界面并制作法纹布。

---

## 🔧 WA脚本代码

```lua
local id = aura_env.id
local gid = id .. "_clickButton"
local region = aura_env.region or WeakAuras.GetRegion(id)
if not region then return end

region:EnableMouse(false)

if _G[gid] then
    _G[gid]:Hide()
    _G[gid] = nil
end

local btn = CreateFrame("Button", gid, region, "SecureActionButtonTemplate")
btn:SetAllPoints(region)
btn:EnableMouse(true)
btn:SetFrameStrata(region:GetFrameStrata())
btn:SetFrameLevel(region:GetFrameLevel() + 10)

btn:RegisterForClicks("AnyUp", "AnyDown")

btn:SetAttribute("type1", "macro")
btn:SetAttribute("macrotext1", [[
/stopcasting
/cast 裁缝
/script for i=1,GetNumTradeSkills() do local n=GetTradeSkillInfo(i); if n and n:find("法纹布") then DoTradeSkill(i,1); TradeSkillFrame:Hide(); break; end end
]])

btn:SetScript("OnEnter", function(self)
        GameTooltip:SetOwner(self, "ANCHOR_RIGHT")
        GameTooltip:ClearLines()
        GameTooltip:AddLine("法纹布", 1, 1, 1)
        GameTooltip:Show()
end)

btn:SetScript("OnLeave", function(self)
        GameTooltip:Hide()
end)

_G[gid] = btn
```

---

## 💡 功能说明

### 主要功能
1. **自动打开裁缝界面** - 点击后自动打开专业技能窗口
2. **智能查找法纹布** - 自动搜索并定位到法纹布制作选项
3. **一键制作** - 自动制作1个法纹布并关闭界面
4. **鼠标悬停提示** - 显示"法纹布"提示信息

### 使用场景
- 快速消耗多余的布料
- 批量制作法纹布用于附魔或出售
- 节省手动操作时间

---

## 🔧 使用方法

### 1. 创建WA
1. 游戏中输入 `/wa` 打开WeakAuras
2. 点击"新增" → "自定义"
3. 类型选择"图标"或"进度条"
4. 在"动作"标签页的"加载时"字段粘贴上述代码

### 2. 配置WA
- **触发器**: 可以设置为始终显示，或根据条件显示
- **显示**: 选择一个合适的图标（如裁缝图标）
- **位置**: 放置在方便点击的位置

### 3. 使用方式
- 点击WA图标即可自动制作法纹布
- 无需手动打开裁缝界面
- 适合批量制作时快速操作

## ⚠️ 注意事项

### 前置要求
- ✅ 已学习裁缝专业
- ✅ 背包中有足够的原始布料
- ✅ WeakAuras插件已安装并启用

### 常见问题
1. **无法制作** - 检查是否学习了裁缝专业
2. **找不到法纹布** - 确认裁缝技能中包含法纹布配方
3. **点击无反应** - 检查WA是否正确加载，查看聊天框是否有错误信息

### 优化建议
- 可以修改 `DoTradeSkill(i,1)` 中的数字来改变制作数量
- 如需制作其他物品，修改 `n:find("法纹布")` 中的物品名称
- 可以添加更多判断逻辑，如材料不足时提示

此脚本模板可以用于其他专业物品的快速制作：


## 📝 技术说明

### 核心API
- `GetNumTradeSkills()` - 获取专业技能数量
- `GetTradeSkillInfo(i)` - 获取第i个技能的信息
- `DoTradeSkill(i,count)` - 制作第i个技能，数量为count
- `TradeSkillFrame:Hide()` - 关闭专业技能窗口

### 安全框架
- 使用 `SecureActionButtonTemplate` 确保在战斗中也能使用
- `SetAttribute("type1", "macro")` 设置点击类型为宏
- `RegisterForClicks("AnyUp", "AnyDown")` 注册鼠标点击事件
