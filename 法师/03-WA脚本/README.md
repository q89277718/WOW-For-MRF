# 法师WA脚本

## 📋 概述

本目录包含法师专用的WeakAuras脚本和相关配置。

---

## ⚡ WA脚本类型

### 输出辅助
- 技能冷却监控
- buff/debuff追踪
- 资源管理提示
- 循环步骤指引

### 生存辅助
- 危险技能预警
- 位移技能提醒
- 保命技能监控

### 团队辅助
- 团队增益监控
- 打断计时器
- 重要机制提醒

---

## 🔧 使用说明

1. 复制WA代码
2. 游戏中输入 `/wa` 打开WeakAuras
3. 点击"导入"粘贴代码
4. 根据需要调整参数
5. 测试确认功能正常

---

## 💡 注意事项

- 确保WeakAuras插件已安装
- 定期检查WA脚本更新
- 根据个人习惯调整显示位置
- 避免过多WA影响游戏性能
